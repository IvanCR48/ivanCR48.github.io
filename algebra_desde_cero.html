1. ¿Por qué el Álgebra es Fundamental?

f(x) = ax + b

El álgebra es la herramienta matemática que permite pasar de la aritmética básica (operaciones con números concretos) a un nivel de abstracción superior mediante el uso de símbolos y variables.

1. Resolución de Problemas Complejos

Permite manejar incógnitas (representadas habitualmente por letras como x, y, z) para plantear y encontrar soluciones exactas en situaciones donde los números por sí solos no bastan.

2. Base para Otras Ciencias e Ingenierías

Comprender álgebra es indispensable para aplicar leyes de la Física (ej. F = m · a, v = v_0 + a · t), Química, Economía, Computación e Ingeniería.

3. Estructura Lógica y Razonamiento

Desarrolla el pensamiento analítico necesario para manipular expresiones mediante reglas específicas, como operaciones con monomios, polinomios, factorización y productos notables.

4. Métodos para Resolver Ecuaciones

Proporciona los métodos para despejar variables en ecuaciones lineales, cuadráticas, racionales, irracionales, exponenciales y logarítmicas, siendo el pilar de todo el cálculo universitario.

2. Productos Notables y Demostraciones Geométricas

Los productos notables son multiplicaciones algebraicas cuyos resultados pueden escribirse directamente mediante fórmulas fijas sin necesidad de realizar toda la distribución paso a paso.

1. Binomio Suma al Cuadrado

(a + b)2 = a2 + 2ab + b2

Demostración Algebraica:
(a + b)2 = (a + b)(a + b) = a · a + a · b + b · a + b · b = a2 + ab + ab + b2 = a2 + 2ab + b2.

Demostración Geométrica del Cuadrado de un Binomio (a + b)2 = a2 + ab + ab + b2

2. Binomio Resta al Cuadrado

(a − b)2 = a2 − 2ab + b2

Demostración Algebraica:
(a − b)2 = (a − b)(a − b) = a2 − ab − ba + b2 = a2 − 2ab + b2.

3. Producto de Binomios Conjugados (Diferencia de Cuadrados)

(a + b)(a − b) = a2 − b2

Demostración Algebraica:
(a + b)(a − b) = a2 − ab + ba − b2 = a2 − b2 (los términos cruzados −ab y +ab se cancelan).

3. Tipos de Ecuaciones y Métodos de Resolución

3.1 Ecuaciones de Primer Grado (Lineales)

Tienen la forma general ax + b = 0 (con a ≠ 0).

Método de Resolución (Balanza de Igualdad):
Se aplican las mismas operaciones matemáticas a ambos miembros de la ecuación para mantener el equilibrio y despejar la incógnita x.

Ejemplo Resuelto Paso a Paso:
Resolver 5x − 8 = 2x + 7:
1. Restamos 2x a ambos miembros: 5x − 2x − 8 = 7 ⇒ 3x − 8 = 7.
2. Sumamos 8 a ambos miembros: 3x = 7 + 8 ⇒ 3x = 15.
3. Dividimos por 3: x = 15 / 3 ⇒ x = 5.

3.2 Ecuaciones de Segundo Grado (Cuadráticas, Bhaskara y Ruffini)

Forma general: ax2 + bx + c = 0 (con a ≠ 0).

1. Fórmula General Resolvente (Fórmula de Bhaskara):

x = [ −b ± √(b2 − 4ac) ] / (2a)

• El término dentro de la raíz Δ = b2 − 4ac se llama Discriminante:
  – Si Δ > 0: Dos soluciones reales distintas.
  – Si Δ = 0: Una solución real doble (x_1 = x_2 = −b/(2a)).
  – Si Δ < 0: No existen soluciones reales (dos raíces complejas conjugadas).

2. Método de Ruffini (División Sintética):
Se utiliza para encontrar raíces enteras de un polinomio evaluando los divisores del término independiente c. Si al evaluar el polinomio en un candidato x = r se obtiene cero (P(r) = 0), entonces (x − r) es un factor del polinomio.

3. Factorización Sacando Factor Común:
Si la ecuación no tiene término independiente (c = 0): ax2 + bx = 0 ⇒ x · (ax + b) = 0.
Por la propiedad del producto nulo: x1 = 0 o bien ax + b = 0 ⇒ x2 = −b / a.

3.3 Ecuaciones Racionales (Incógnita en el Denominador)

Son aquellas donde la incógnita x aparece en el denominador de alguna fracción algebraicas.

PASO OBLIGATORIO - Restricciones de Dominio:
Dado que la división por cero no está definida en los reales, se debe establecer antes de operar que ningún denominador sea igual a cero (Q(x) ≠ 0).

Método de Resolución (Linealización):
Se multiplican ambos miembros por el Mínimo Común Denominador (MCD) para eliminar las fracciones y obtener una ecuación lineal o cuadrática equivalente.

Ejemplo Resuelto Paso a Paso:
Resolver 3 / (x − 2) = 5 / (x + 4):
1. Restricciones: x − 2 ≠ 0 ⇒ x ≠ 2  y  x + 4 ≠ 0 ⇒ x ≠ −4.
2. Multiplicamos cruzado: 3(x + 4) = 5(x − 2).
3. Aplicamos distributiva: 3x + 12 = 5x − 10.
4. Agrupamos términos: 12 + 10 = 5x − 3x ⇒ 22 = 2x ⇒ x = 11.
5. Verificamos con las restricciones: Como 11 ≠ 2 y 11 ≠ −4, la solución es válida.

3.4 Ecuaciones Irracionales (Radicales)

Son aquellas donde la incógnita x se encuentra dentro del radicado de una raíz (ej. √P(x)).

Método de Resolución:
1. Aislamos el término que contiene la raíz en uno de los miembros de la igualdad.
2. Elevamos ambos miembros al cuadrado (o a la potencia según el índice del radical) para eliminar la raíz.
3. Resolvemos la ecuación resultante.

PASO OBLIGATORIO - Verificación de Soluciones Extrañas:
Elevar ambos lados al cuadrado puede introducir "soluciones falsas" o extrañas (ya que A2 = B2 no garantiza que A = B, pudendo ser A = −B). Por lo tanto, es imprescindible reemplazar cada solución obtenida en la ecuación original para confirmar su validez.

Ejemplo Resuelto Paso a Paso:
Resolver √(x + 5) = x − 1:
1. Elevamos al cuadrado: [√(x + 5)]2 = (x − 1)2 ⇒ x + 5 = x2 − 2x + 1.
2. Igualamos a cero: x2 − 3x − 4 = 0.
3. Aplicamos Bhaskara: x = [3 ± √(9 − 4(1)(−4))] / 2 = [3 ± 5] / 2 ⇒ x1 = 4, x2 = −1.
4. Verificación:
  • Para x = 4: √(4 + 5) = 4 − 1 ⇒ √9 = 3 ⇒ 3 = 3 (¡VÁLIDA!).
  • Para x = −1: √(−1 + 5) = −1 − 1 ⇒ √4 = −2 ⇒ 2 ≠ −2 (¡FALSA / EXTRAÑA!).
Resultado final: La única solución real es x = 4.

3.5 Ecuaciones Exponenciales

Son aquellas donde la incógnita x forma parte del exponente de una potencia (ej. af(x) = c).

Métodos de Resolución:
Caso A (Igualación de Bases): Se busca expresar ambos miembros como potencias de una misma base a. Utilizando la propiedad de inyectividad:

af(x) = ag(x) ⇒ f(x) = g(x)

Ejemplo: 23x − 1 = 16 ⇒ 23x − 1 = 24 ⇒ 3x − 1 = 4 ⇒ 3x = 5 ⇒ x = 5/3.

Caso B (Uso de Logaritmos): Cuando las bases no pueden reducirse a una común, se aplican logaritmos en ambos miembros:
Ejemplo: 3x = 7 ⇒ ln(3x) = ln(7) ⇒ x · ln(3) = ln(7) ⇒ x = ln(7) / ln(3) ≈ 1,771.

3.6 Ecuaciones Logarítmicas

Están íntimamente relacionadas con las exponenciales. La incógnita x aparece dentro del argumento de un logaritmo (ej. log_b(f(x)) = c).

Definición de Logaritmo: El logaritmo en base b de un número es el exponente al cual se debe elevar la base b para obtener dicho número:

logb(A) = c ⇔ bc = A     (con A > 0, b > 0, b ≠ 1)

Propiedades Clave para Agrupar Logaritmos:
• log_b(A) + log_b(B) = log_b(A · B).
• log_b(A) − log_b(B) = log_b(A / B).
• n · log_b(A) = log_b(An).

Ejemplo Resuelto Paso a Paso:
Resolver log_2(x + 3) + log_2(x − 3) = 4:
1. Agrupamos con el producto de argumentos: log_2[(x + 3)(x − 3)] = 4.
2. Aplicamos la definición de logaritmo: (x + 3)(x − 3) = 24 = 16.
3. Por diferencia de cuadrados: x2 − 9 = 16 ⇒ x2 = 25 ⇒ x = ±5.
4. Verificación del dominio (Argumento > 0):
  • Para x = 5: 5 + 3 = 8 > 0 y 5 − 3 = 2 > 0 (¡VÁLIDO!).
  • Para x = −5: −5 + 3 = −2 < 0 (¡INVÁLIDO, no existen logaritmos de números negativos!).
Resultado final: x = 5.

4. Ejercicios Prácticos de Autoevaluación

Ejercicio 1: Aplicación de Productos Notables

Desarrollar la expresión (3x − 4)2 utilizando la fórmula del binomio resta al cuadrado.

Ver Resolución Paso a Paso

1. Aplicamos (a − b)2 = a2 − 2ab + b2 con a = 3x y b = 4.
2. (3x)2 − 2(3x)(4) + 42 = 9x2 − 24x + 16.

Ejercicio 2: Ecuación Racional con Restricción

Resolver la ecuación (2x + 1) / (x − 3) = 5 y verificar su validez en el dominio.

Ver Resolución Paso a Paso

1. Restricción: x − 3 ≠ 0 ⇒ x ≠ 3.
2. Multiplicamos por el denominador: 2x + 1 = 5(x − 3).
3. Distributiva: 2x + 1 = 5x − 15 ⇒ 16 = 3x ⇒ x = 16/3.
4. Como 16/3 ≠ 3, la solución es válida.

Ejercicio 3: Ecuación Exponencial con Cambio de Base

Hallar la solución de la ecuación exponencial 9x − 1 = 27x + 2 reduciendo ambos miembros a potencias de base 3.

Ver Resolución Paso a Paso

1. Expresamos como base 3: 9 = 32 y 27 = 33.
2. Sustituimos: (32)x − 1 = (33)x + 2 ⇒ 32x − 2 = 33x + 6.
3. Igualamos exponentes: 2x − 2 = 3x + 6 ⇒ −2 − 6 = 3x − 2x ⇒ x = −8.
