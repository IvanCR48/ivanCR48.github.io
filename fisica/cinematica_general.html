1.1.1 Cinemática de la Partícula

r(t) = (x(t), y(t))

Una rama muy importante de la Física es la Mecánica, que estudia los cuerpos, sus movimientos y las causas que los generan. Se divide en dos grandes áreas:

Cinemática vs. Dinámica

• Cinemática: Estudia y describe el movimiento de los cuerpos sin tener en cuenta las causas que lo producen (analiza posición, trayectoria, velocidad y aceleración).
• Dinámica: Estudia el movimiento relacionándolo directamente con las fuerzas y causas que lo generan.

¿Cuándo un cuerpo puede ser tratado como una Partícula?

Una partícula (o punto material) es un cuerpo cuyas dimensiones espaciales son despreciables frente a las distancias del movimiento estudiado.

Criterio Fundamental: Un cuerpo extenso puede ser estudiado como una partícula cuando el movimiento de interés puede ser descrito con el movimiento de un solo punto representativo del cuerpo.

Ejemplo Ilustrativo: Al estudiar el movimiento de traslación de la Tierra alrededor del Sol, las dimensiones de la Tierra (radio ≈ 6.371 km) son insignificantes comparadas con la distancia al Sol (≈ 150.000.000 km). Si no interesa estudiar la rotación propia del planeta sobre su eje (día/noche), la Tierra se modela perfectamente como una partícula puntual en órbita.

1.1.2 Magnitudes del Movimiento

Para describir cuantitativamente el movimiento de una partícula se definen las siguientes magnitudes fundamentales:

Magnitudes Principales

1. Sistema de Referencia: Conjunto de ejes coordenados (ej. cartesiano XY) con un origen fijado en el espacio y un reloj de medición.
2. Tiempo (t) e Intervalo Temporal (Δt): El tiempo es una magnitud escalar. El intervalo transcurrido entre un instante inicial ti y un instante final tf se define como:

Δt = tf − ti     (Δt > 0)

3. Vector Posición r(t): Vector que une el origen del sistema de referencia con la ubicación de la partícula en el instante t. Sus componentes cartesianas son:

r(t) = (x(t), y(t))   [m]   o en notación de versores:   r(t) = x(t) i + y(t) j

4. Vector Desplazamiento / Incremento de Posición (Δr): Diferencia vectorial entre la posición final y la posición inicial durante un intervalo Δt:

Δr = r(tf) − r(ti) = (x(tf) − x(ti), y(tf) − y(ti))   [m]

Diferencia Clave: El desplazamiento es una magnitud vectorial secante a la trayectoria (une en línea recta la posición inicial y final). El camino recorrido (s) es una magnitud escalar que mide la longitud total del trayecto recorrido sobre la curva.

1.1.3 Vector Velocidad Media e Instantánea

1. Vector Velocidad Media (vm)

El vector velocidad media entre dos instantes t_i y t_f se define como el cociente entre el vector desplazamiento Δ\mathbf{r} y el intervalo temporal Δt:

vm = Δr / Δt = ( Δx / Δt, Δy / Δt )   [m/s]

• Es el resultado de dividir un vector por un escalar positivo (Δt > 0), por lo que la velocidad media tiene exactamente la misma dirección y sentido que el vector desplazamiento Δr.

2. Vector Velocidad Instantánea (v) y Rapidez

Cuando el intervalo de tiempo se hace infinitamente pequeño (Δt → 0), la posición final se aproxima a la inicial y el desplazamiento tiende a confundirse con la trayectoria.

v(t) = limΔt → 0 (Δr / Δt) = dr / dt   [m/s]

Propiedades Fundamentales:
• Dirección y Sentido: El vector velocidad instantánea \mathbf{v}(t) es siempre TANGENTE a la trayectoria en cada punto y apunta en el sentido del movimiento.
• Rapidez (v): Es el módulo o intensidad del vector velocidad instantánea: v = |\mathbf{v}| = √(v_x2 + v_y2).

1.1.4 Vector Aceleración

Cualquier cambio en el vector velocidad (ya sea en su módulo/rapidez, en su dirección o en su sentido) implica la existencia de un vector aceleración.

Aceleración Media e Instantánea

• Vector Aceleración Media (am): Cociente entre la variación del vector velocidad Δ\mathbf{v} = \mathbf{v}(t_f) − \mathbf{v}(t_i) y el intervalo temporal Δt:

am = Δv / Δt = ( v(t_f) − v(t_i) ) / Δt   [m/s2]

• Vector Aceleración Instantánea (a): Límite cuando Δt → 0 de la aceleración media:

a(t) = limΔt → 0 (Δv / Δt) = dv / dt   [m/s2]

Causas de Aceleración:
1) Si pisa el acelerador o freno ⇒ Cambia el módulo de la velocidad (aparece aceleración tangencial).
2) Si gira el volante ⇒ Cambia la dirección de la velocidad (aparece aceleración centrípeta/normal).

1.1.5 Ejemplo Analítico Desarrollado (Módulo UNMDP)

Problema del Movimiento de la Cucaracha sobre Cuadrícula

Una cucaracha camina sobre un piso de cerámicos cuadrados de 0,6 m × 0,6 m. Se registra su vector posición r(t) en diferentes instantes de tiempo:
• r(0s) = (0 ; 0) m
• r(1s) = (0,3 ; 1,2) m
• r(2s) = (0,6 ; 1,2) m
• r(4s) = (0,6 ; 0,6) m
• r(6s) = (1,2 ; 0,6) m
• r(8s) = (1,2 ; 0) m

1. Vectores Desplazamiento (Δr):
Restando analíticamente las componentes extremas menos las iniciales:
• Entre 0s y 2s:  Δr0→2 = r(2) − r(0) = (0,6 − 0 ; 1,2 − 0) = (0,6 ; 1,2) m.
• Entre 1s y 4s:  Δr1→4 = r(4) − r(1) = (0,6 − 0,3 ; 0,6 − 1,2) = (0,3 ; −0,6) m.
• Entre 6s y 8s:  Δr6→8 = r(8) − r(6) = (1,2 − 1,2 ; 0 − 0,6) = (0 ; −0,6) m.

2. Vectores Velocidad Media (vm):
Dividiendo cada vector desplazamiento por su respectivo intervalo de tiempo Δt:
• Entre 0s y 2s (Δt = 2s):  vm = (0,6 / 2 ; 1,2 / 2) = (0,3 ; 0,6) m/s.
• Entre 1s y 4s (Δt = 3s):  vm = (0,3 / 3 ; −0,6 / 3) = (0,1 ; −0,2) m/s.
• Entre 6s y 8s (Δt = 2s):  vm = (0 / 2 ; −0,6 / 2) = (0 ; −0,3) m/s.

1.1.6 Ejercicios Prácticos de Autoevaluación

Ejercicio 1: Cálculo de Desplazamiento Vectorial

Un objeto se encuentra en r(1s) = (2 ; 5) m y a los t = 5s alcanza la posición r(5s) = (14 ; −1) m. Hallar el vector desplazamiento Δr y su módulo.

Ver Resolución

1. Δr = r(5) − r(1) = (14 − 2 ; −1 − 5) = (12 ; −6) m.
2. Módulo: |\Delta r| = √(122 + (−6)2) = √(144 + 36) = √180 ≈ 13,42 m.

Ejercicio 2: Velocidad Media Vectorial

Con los datos del Ejercicio 1, determinar las componentes del vector velocidad media vm y su rapidez media.

Ver Resolución

1. Intervalo temporal: Δt = 5s − 1s = 4s.
2. vm = Δr / Δt = (12 / 4 ; −6 / 4) = (3 ; −1,5) m/s.
3. Módulo de velocidad media: |vm| = 13,42 / 4 ≈ 3,35 m/s.

Ejercicio 3: Aceleración Media por Cambio de Dirección

Un vehículo viaja hacia el Este a v1 = (20 ; 0) m/s y al cabo de t = 2s gira hacia el Norte manteniendo rapidez constante, teniendo v2 = (0 ; 20) m/s. Calcular el vector aceleración media am.

Ver Resolución

1. Variación de velocidad: Δv = v2 − v1 = (0 − 20 ; 20 − 0) = (−20 ; 20) m/s.
2. Aceleración media: am = Δv / Δt = (−20 / 2 ; 20 / 2) = (−10 ; 10) m/s2.
3. Módulo: |am| = √((−10)2 + 102) = √200 ≈ 14,14 m/s2.
