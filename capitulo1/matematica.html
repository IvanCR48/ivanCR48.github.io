Breve historia del numero

La nocion de numero es tan antigua como el hombre mismo. Las tribus mas primitivas disponian de simbolos para distinguir entre uno, dos, tres...

Prehistoria

El numero natural

El hombre primitivo poseia la idea del numero natural (1, 2, 3, 4...). Hasta la Edad de Bronce no aparecen sistemas de numeracion potentes.

~2000 a.C. — Egipto

El numero fraccionario

Los egipcios comienzan a manejar fracciones sencillas: 1/2, 1/3, 2/3, 6/7... Los griegos elevan estas manipulaciones a la categoria de Ciencia.

Siglo V a.C. — Grecia

Aparicion del irracional

Los pitagoricos descubren que la diagonal y el lado de un cuadrado tienen un cociente que no es una fraccion. Llamaron a este tipo de numero alogos (irracional).

Siglo XVI-XVII — Europa

El numero negativo

La resolucion de ecuaciones algebraicas conduce a los numeros negativos. En geometria: lo negativo indica retroceso, lo positivo avance. Los chinos ya los usaban desde el siglo IV a.C. con bolas de abaco.

Siglo XIX

Los complejos

Al resolver ecuaciones como x² - 2x + 26 = 0 aparecen expresiones como √(-25). Su fundamentacion moderna no llego hasta mediados del siglo XIX.

Numeros Naturales

N

Definicion

Son los numeros que utilizamos para contar:

N = { 1, 2, 3, 4, 5, 6, 7, ... }

Si incluimos el cero, se escribe N0 = { 0, 1, 2, 3, 4, ... }

Recta numerica de los Naturales

Cerrado bajo la suma

a + b ∈ N

3 + 5 = 8 ∈ N

Cerrado bajo el producto

a · b ∈ N

4 · 7 = 28 ∈ N

NO cerrado bajo la resta

a - b ∉ N (si a < b)

3 - 9 = -6 ∉ N

NO cerrado bajo la division

a / b ∉ N (en general)

7 / 2 = 3.5 ∉ N

Problema motivador

La ecuacion x + 9 = 3 tiene coeficientes naturales, pero no tiene solucion en N. Para resolverla necesitamos restar 9 en ambos miembros:

x + 9 - 9 = 3 - 9
x = -6

Necesitamos un conjunto mas grande: los numeros enteros.

Numeros Enteros

Z

Definicion

Son los numeros naturales, sus opuestos (negativos) y el cero:

Z = { ..., -3, -2, -1, 0, 1, 2, 3, ... }

La letra Z proviene del aleman Zahlen (numeros).

Recta numerica de los Enteros

Relacion de contenencia

N ⊂ Z

Todo numero natural es tambien un numero entero.

Cerrado bajo la suma

a + b ∈ Z

(-3) + 5 = 2 ∈ Z

Cerrado bajo la resta

a - b ∈ Z

2 - 7 = -5 ∈ Z

Cerrado bajo el producto

a · b ∈ Z

(-3) · 4 = -12 ∈ Z

NO cerrado bajo la division

a / b ∉ Z (en general)

5 / 3 ∉ Z

Problema motivador

La ecuacion 2x + 5 = 6 no tiene solucion entera:

2x = 6 - 5 = 1
x = 1/2

Necesitamos un conjunto mas grande: los numeros racionales.

Numeros Racionales

Q

Definicion

La palabra "racional" viene de razon o proporcion. Un numero racional es el resultado de la razon entre dos enteros:

Q = { p/q | p ∈ Z, q ∈ Z, q ≠ 0 }

Donde p es el numerador y q el denominador.

Ejemplos y su representacion decimal

Fraccion Decimal Tipo de decimal
1/2 0,5 Exacto (finito)
-3/5 -0,6 Exacto (finito)
2/4 0,5 Exacto (igual a 1/2)
22/3 7,333... Periodico (periodo: 3)
1821/7 260,142857... Periodico (periodo: 142857)
13/6 2,1666... Semiperiodico (periodo: 6)

Recta numerica: los racionales llenan los "huecos"

Propiedad clave de los racionales

Todo numero racional tiene una expansion decimal que es:

Decimal exacto (finito)

1/4 = 0,25

Cantidad finita de digitos despues de la coma.

Decimal periodico

22/3 = 7,333...

Un grupo finito de digitos (el periodo) se repite infinitamente.

Decimal semiperiodico

13/6 = 2,1666...

Comienza con digitos no repetitivos (anteperiodo) y luego se repite un periodo.

Nota importante

Distintas fracciones pueden representar el mismo numero racional. Por ejemplo: 1/2 = 2/4 = 3/6 = 50/100. Se llaman fracciones equivalentes.

Problema motivador

La ecuacion x² - 2 = 0 no tiene solucion racional:

x² = 2 ⇒ x = √2 = 1,41421356...

Este decimal es infinito y no tiene periodo. No se puede expresar como fraccion p/q. Necesitamos los numeros irracionales.

Numeros Irracionales

I

Definicion

Son aquellos cuya expresion decimal es infinita y no tiene periodo. No pueden expresarse como fraccion p/q.

I = { x ∈ R | x ∉ Q }

Irracionales famosos

Simbolo Nombre Valor aproximado Descripcion
π Pi 3,14159265358... Razon entre la circunferencia y su diametro
e Numero de Euler 2,71828182845... Base del logaritmo natural
√2 Raiz de 2 1,41421356237... Diagonal de un cuadrado de lado 1
√3 Raiz de 3 1,73205080756... Diagonal de un rectangulo 1x√2
√p Raiz de primo --- √p es irracional para todo primo p

Como construir un irracional

Podemos generar un irracional no famoso construyendo un decimal infinito sin periodo:

1 1,1
2 1,101
3 1,101001
4 1,1010010001
... 1,101001000100001...

Cada vez agregamos un "1" separado por una cantidad creciente de ceros. No hay forma de encontrar un grupo de digitos que se repita, por lo tanto es irracional.

El cuadrado de Pitagoras: origen de √2

Racional vs Irracional: la diferencia clave

Racional (Q)

22/7 = 3,142857142857...

El bloque 142857 se repite para siempre.

Se puede escribir como fraccion p/q

Irracional (I)

π = 3,14159265358979323846...

Los digitos continuan sin repetir ningun patron.

NO se puede escribir como fraccion p/q

Numeros Reales

R

Definicion

La union de los numeros racionales y los irracionales forman el conjunto de los numeros reales:

R = Q ∪ I

Cada punto de la recta numerica corresponde a exactamente un numero real, y cada numero real corresponde a un punto de la recta.

Diagrama de conjuntos anidados

Cadena de contenencia

N ⊂ Z ⊂ Q ⊂ R

Todo natural es entero, todo entero es racional, y todo racional es real.
Los irracionales son reales que no son racionales: I = R ∖ Q.

Limite del campo real

Los reales tampoco resuelven todas las ecuaciones. La ecuacion x² + 1 = 0 no tiene solucion en R, ya que requiere x = √(-1). Para eso existen los numeros complejos (tema posterior).

Propiedades de los Numeros Reales

Sean a, b, c numeros reales.

Propiedad Suma (+) Producto (·)
Conmutativa a + b = b + a a · b = b · a
Asociativa (a + b) + c = a + (b + c) (a · b) · c = a · (b · c)
Elemento neutro a + 0 = a a · 1 = a
Elemento inverso a + (-a) = 0 a · (1/a) = 1  (a ≠ 0)

Distributividad

Valida

a · (b + c) = a·b + a·c

El producto distribuye sobre la suma.

Valida

(a + b) / c = a/c + b/c

El cociente distribuye sobre la suma si la suma esta en el numerador (c ≠ 0).

NO valida

a / (b + c) ≠ a/b + a/c

La suma en el denominador no se puede distribuir.

Ejemplo: 12/(3+2) = 12/5 = 2,4   pero   12/3 + 12/2 = 4 + 6 = 10

Propiedades sobre igualdades

Si a = b, entonces a + c = b + c

Se puede sumar (o restar) lo mismo a ambos miembros.

Si a = b, entonces a · c = b · c

Se puede multiplicar ambos miembros por lo mismo.

Si a = b y c ≠ 0, entonces a/c = b/c

Se puede dividir ambos miembros por lo mismo (no nulo).

Si a · b = 0, entonces a = 0 o b = 0

Propiedad del producto nulo: si un producto es cero, al menos uno de los factores es cero.

Preguntas Clave y Fundamentos Conceptuales

Respuestas profundas y rigurosas a las dudas estructurales sobre los números, conjuntos y operaciones del álgebra elemental.

1. ¿Por qué en N no podés restar cuando el resultado es negativo? ¿Por qué nacen los Enteros (Z)?

En el conjunto de los Naturales N = {1, 2, 3, ...}, la resta a − b solo es posible si a > b. Se dice que N NO es cerrado bajo la resta.

Si intentamos resolver la ecuación elemental x + 9 = 3, despejar x requiere calcular 3 − 9, cuyo resultado no existe en N. Para resolver este "vacío" algebraico y poder representar cantidades por debajo de cero (deudas, temperaturas bajo cero, posiciones submarinas), fue necesario inventar los Números Enteros Z, agregando los opuestos negativos {..., −3, −2, −1} y el cero 0.

2. ¿Por qué en Z no podés dividir cuando el resultado no es entero?

En los Enteros Z, la división a / b (con b ≠ 0) busca un entero x tal que b · x = a.
Por ejemplo, en 5 / 2 = x ⇒ 2 · x = 5, no existe ningún número entero que multiplicado por 2 dé 5. En Z no existen inversos multiplicativos (salvo para 1 y −1).

Esto obliga a ampliar el sistema numérico creando los Números Racionales Q, definidos como todas las cocientes posibles entre dos enteros: Q = { p/q | p ∈ Z, q ∈ Z, q ≠ 0 }.

3. ¿Por qué en Q no podés sacar √2 (ni π, ni e)? Demostración de Irracionalidad

Un número como √2 NO es racional porque no existe ninguna fracción de enteros p/q que elevada al cuadrado dé exactamente 2.

Demostración clásica por Reducción al Absurdo (Pitágoras):
1. Supongamos que √2 = p/q, donde p/q es una fracción irreducible (sin factores comunes entre p y q).
2. Elevando ambos miembros al cuadrado: 2 = p2 / q2 ⇒ p2 = 2q2.
3. Esto significa que p2 es un número par. Por propiedad entera, si el cuadrado de un número es par, el número p también debe ser par. Así que podemos escribir p = 2k.
4. Reemplazando p en la ecuación: (2k)2 = 2q2 ⇒ 4k2 = 2q2 ⇒ q2 = 2k2.
5. ¡Esto significa que q2 también es par, por lo que q debe ser par!
6. Contradicción: Si p y q son ambos pares, la fracción p/q se podía simplificar dividiendo por 2, lo cual contradice la suposición inicial de que era irreducible.

Conclusión: √2 no se puede escribir como fracción p/q. Lo mismo ocurre con constantes trascendentes como π ≈ 3,14159... y e ≈ 2,71828..., cuyos decimales son infinitos y no periódicos.

4. ¿Por qué R = Q ∪ I? ¿Qué es ∪?

• El símbolo ∪ representa la Unión de Conjuntos (el conjunto que reúne a todos los elementos que pertenecen a al menos uno de los conjuntos dados).
• Los Racionales Q (decimales finitos y periódicos) y los Irracionales I (decimales infinitos no periódicos) son conjuntos completamente disjuntos (ningún número puede ser racional e irracional a la vez: Q ∩ I = ∅).
• Al hacer R = Q ∪ I, "pegamos" ambos conjuntos para formar la recta numérica continua de los Números Reales R, llenando absolutamente todos los puntos sobre la recta sin dejar ningún agujero.

5. ¿Qué es un Conjunto, Suma, Resta, Producto y División?

• Conjunto: Colección bien definida de objetos o elementos distintos (ej. N = \{1, 2, 3, \dots\}).
• Suma (Adición): Operación primaria que combina dos cantidades para obtener una suma total.
• Resta (Sustracción): Operación inversa a la suma. En álgebra, restar b es equivalente a sumar el opuesto aditivo de b: a − b = a + (−b).
• Producto (Multiplicación): Operación que representa la suma abreviada de una cantidad tantas veces como indica la otra (o el escalamiento continuo en R).
• División (Cociente): Operación inversa al producto. Dividir por b es equivalente a multiplicar por el inverso multiplicativo de b: a / b = a · (1/b) (con b ≠ 0).

6. ¿Cómo distinguir Racional de Irracional?

Racional (Q): Se puede escribir como fracción p/q. Su expansión decimal es:
1) Finita / Exacta: 1/4 = 0,25.
2) Infinita Periódica: 1/3 = 0,333... (el 3 se repite infinitamente).

Irracional (I): NO se puede escribir como fracción p/q. Su expansión decimal es infinita y NO tiene ningún patrón repetitivo (NO periódica). Ejemplos: √2 = 1,41421356..., π = 3,14159265....

7. ¿Qué es un número Periódico y Semiperiódico?

• Periódico (Puro): La secuencia repetitiva (el período) empieza inmediatamente después de la coma decimal.
Ejemplo: 22/7 = 3,142857142857... = 3,&overline;142857 (período: 142857).

• Semiperiódico (Mixto): Existen cifras no repetitivas entre la coma decimal y el período (llamadas anteperíodo).
Ejemplo: 13/6 = 2,1666... = 2,1&overline;6 (anteperíodo: 1; período: 6).

8. Axiomas de los Reales: Conmutativa, Asociativa, Neutro, Inverso y Distributividad

• Conmutativa: El orden de los elementos no altera el resultado (a + b = b + a ; a · b = b · a).
• Asociativa: La forma de agruparlos no altera el resultado ((a + b) + c = a + (b + c) ; (a · b) · c = a · (b · c)).
• Elemento Neutro: Deja el número idéntico. En la suma es el 0 (a + 0 = a); en el producto es el 1 (a · 1 = a).
• Elemento Inverso: Al operar con el número, produce el elemento neutro. En la suma es el opuesto −a (a + (−a) = 0); en el producto es el recíproco 1/a (a · (1/a) = 1, para a ≠ 0).
• Distributividad: Conecta el producto con la suma: a · (b + c) = a · b + a · c.

9. ¿Por qué a / (b + c) ≠ a/b + a/c? ¿Qué significa ≠?

• El símbolo ≠ significa "diferente de" o "no es igual a".

• ¿Por qué NO distribuye el denominador?
La división por una suma equivale a multiplicar por el inverso de la suma: a / (b+c) = a · \frac{1}{b+c}. Pero el inverso de una suma NO es la suma de los inversos: \frac{1}{b+c} ≠ \frac{1}{b} + \frac{1}{c}.

Contraejemplo Numérico: Sean a = 12, b = 3, c = 2.
• Miembro izquierdo: 12 / (3 + 2) = 12 / 5 = 2,4.
• Miembro derecho: 12/3 + 12/2 = 4 + 6 = 10.
Como 2,4 ≠ 10, queda demostrado que la regla es un error gravísimo. Recuerda: El cociente solo distribuye si la suma está en el numerador: (b + c) / a = b/a + c/a.

10. ¿A qué se refiere el Cálculo Infinitesimal?

El Cálculo Infinitesimal (o simplemente Cálculo) es la rama fundamental de la matemática que se ocupa del estudio del cambio continuo y de las cantidades infinitamente pequeñas (infinitesimales). Se divide en dos pilares interconectados:

1. Cálculo Diferencial: Estudia las tasas de cambio instantáneas a través del concepto de Derivada (por ejemplo, cómo varía la velocidad de un móvil en cada instante exacto de tiempo o la pendiente de la tangente a una curva).
2. Cálculo Integral: Estudia la acumulación de cantidades continuas mediante la Integral (por ejemplo, el área exacta debajo de una curva compleja o la distancia total recorrida dada una velocidad variable).
